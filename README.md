# 麦麦内容工坊 mcd-content-studio

> 给一个主题，基于麦当劳 MCP 的真实数据，一次产出小红书笔记、公众号推文、短视频口播稿三套内容。

本项目是「麦当劳程序员创意开发大赛」参赛作品，由参赛者独立开发，非麦当劳官方产品。

## 项目介绍

做麦当劳内容的博主和门店运营，日常卡在三件事上：不知道写什么、数据不敢编、一条素材要改三遍。

麦麦内容工坊把这三件事合成一条流水线：先通过麦当劳 MCP 拉取**当前门店真实在售菜单**和**当月官方活动日历**，再自动挑出内容由头，最后按三个平台各自的体例分别成稿。

## 目标用户

| 人群 | 使用场景 |
|---|---|
| 美食博主 / 探店账号 | 找不到选题、不想手动查价格和热量 |
| 品牌与门店内容运营 | 官方活动上线后要快速产出配套内容 |
| 本地生活类账号主理人 | 一稿多平台分发，省掉重复改稿 |

## 安装方法

### 前置条件

- 已申请麦当劳 MCP Token（在 https://open.mcd.cn/mcp 手机号登录后，于控制台激活获取）
- 使用支持 Streamable HTTP 的 MCP 客户端（WorkBuddy / Cherry Studio / Cursor / Trae 等）

### 配置 MCP

将 `mcp-config.example.json` 中的 `YOUR_MCP_TOKEN` 替换为你自己的 Token，填入客户端的 MCP 配置：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

保存后启用该连接器即可。

### 安装本 Skill

将本目录整体放入你的 MCP 客户端的技能目录，或作为项目目录打开。

## 使用示例

**示例一**

> 帮我写一篇关于麦当劳当前在售早餐的内容，三个平台都要。

Skill 会调用 `query-meals` 拉取当前在售早餐菜单，调用 `campaign-calendar` 检查是否有配套活动，然后输出小红书、公众号、口播三份成稿。

**示例二**

> 本周有什么活动值得写？给我一个选题和一篇小红书笔记。

Skill 会从活动日历里挑出正在进行且剩余时间最短的活动，围绕它生成选题角与成稿。

**示例三**

> 帮我对比一下现在在售的几款套餐哪个性价比高，写成推文。

Skill 会拉取在售套餐与价格，做客观的价格与内容物对照（不做与其他品牌的比较），输出公众号格式。

## 输出物

每次执行会在指定目录生成一个内容包：

```
mcd-content-YYYYMMDD-<主题>/
├── 00-数据底稿.md      # MCP 原始返回数据，供核对
├── 01-小红书.md
├── 02-公众号.md
└── 03-口播脚本.md
```

`00-数据底稿.md` 用于证明成稿中的每一个数字都有出处。

## 安全说明

- 默认只执行只读查询，不涉及下单、领券、兑换。
- 任何写操作类工具调用，都会先完整展示动作与影响范围，经用户明确同意后才执行。
- 全部餐品信息、价格与营养数据均来自麦当劳 MCP 实时返回，不做推测填充。
- 输出内容不包含与其他品牌的对比，不做健康功效承诺。

## 声明

餐品信息、价格及供应状态以麦当劳官方渠道的实时结果为准。
