# 三平台体例指南

同一份素材，三个平台各有各的写法。下面是本 Skill 遵循的体例规范。

## 一、小红书版

**受众心理**：滑手机的人只给 1 秒。标题不抓人，内容白写。

**结构**
1. 标题：14-20 字，带数字或价格锚点，可用一个表情符号收尾
2. 开头一句：直接给结论或反差，不铺垫
3. 正文：3-5 个短段，每段 1-2 句，段间空行
4. 收尾一句：引导互动（问一句，不要喊口号）
5. 话题标签：4-6 个，含 1 个品牌词 + 2 个场景词 + 1 个地域或人群词

**字数**：300-600 字。超过就删，不要心疼。

**禁忌**：不写"姐妹们冲"这类烂大街开场；不与其他品牌比较。

## 二、公众号版

**受众心理**：点进来的人愿意读，但 3 秒内没看到有用信息就走。

**结构**
1. 标题：直白给利益点，不用标题党
2. 开头 2 段：从一个具体场景切入，引出本篇要解决什么
3. 主体 3-4 节，每节一个小标题，节内先结论后说明
4. 数据引用：价格、营养成分，逐项标注取自麦当劳官方数据
5. 结尾：给一个可立刻执行的动作建议 + 一个互动问题

**字数**：按需，通常 1200-2000 字。宁可短而有用，不要为凑字数注水。

**禁忌**：不堆砌形容词；不用"众所周知""不得不说"这类填充词。

## 三、口播版（短视频）

**受众心理**：前 3 秒决定划不划走。

**结构**

```
【时长】60-90 秒
【前 3 秒钩子】一句让人停住的话

分镜 1（0-5s）  画面：xxx  口播：xxx
分镜 2（5-20s） 画面：xxx  口播：xxx
分镜 3（20-45s）画面：xxx  口播：xxx
分镜 4（45-60s）画面：xxx  口播：xxx
【收尾 CTA】一句行动指引
```

**规范**
- 口播逐字稿按口语写，一句不超过 20 字，方便直接念
- 每 15 秒安排一个信息点或转折，防止划走
- 价格、营养数据出镜时，同时在画面角标注明"数据来源：麦当劳官方"

## 通用规则（三个平台都适用）

1. **数字有出处**。所有价格、热量、营养成分必须来自 MCP 实际返回，无法取得就不写。
2. **不做功效承诺**。不出现"吃了能瘦""健康无害"这类表述。
3. **不横向对比**。不提及任何其他餐饮品牌。
4. **结尾统一声明**：餐品信息、价格及供应状态以麦当劳官方渠道实时结果为准。
